  o'rnatish paytida internet SO'RALMAYDI.

----------------------------------------------------------------
  2-QADAM. PostgreSQL
----------------------------------------------------------------

  Yuklab olingan faylni ishga tushiring -> Next.

  * "postgres" foydalanuvchisiga PAROL so'raydi.
    SHU PAROLNI YOZIB QO'YING — 3-qadamda kerak bo'ladi.
  * Port: 5432 (o'zgartirmang).
  * Oxirida "Stack Builder" oynasi ochiladi ->
    CANCEL (ruscha "Otmena") bosing.
    U internetdan qo'shimcha dastur yuklaydi, LabCore uchun kerak emas.

  Ikkalasidan keyin kompyuterni QAYTA YOQING.


----------------------------------------------------------------
  3-QADAM. LabCore
----------------------------------------------------------------

  Arxivni C:\ diskiga chiqaring (o'ng tugma -> Extract All).

  "ORNATISH.bat" -> O'NG TUGMA -> "Run as administrator"

  Skript PostgreSQL parolini so'raydi, qolganini o'zi qiladi.
  5-10 daqiqa kutasiz. Oxirida ekranda chiqadi:

        Server manzili : https://192.168.1.XX:4000
        login: admin       parol: Admin12345

  SERVER MANZILINI YOZIB OLING — xodim kompyuterlariga va
  telefonga aynan shu manzil kiritiladi.

  Ish stolida ikkita belgicha paydo bo'ladi:
     LabCore                      - tizimning o'zi
     LabCore - telefonga ulash    - QR kod sahifasi

  Kompyuter yoqilganda LabCore endi o'zi ochiladi.


----------------------------------------------------------------
  4-QADAM. Xodim kompyuterlari
----------------------------------------------------------------

  "LabCore-DASTUR.exe" ni har bir xodim kompyuteriga ko'chiring
  (fleshka yoki tarmoq orqali) va ishga tushiring. O'rnatish shart emas.

  Birinchi ochilganda server manzilini so'raydi -> 3-qadamda
  yozib olgan manzilni kiriting -> "Ulanishni tekshirish" ->
  laboratoriya nomi chiqsa -> "Saqlash va davom etish".

  Avtozapusk (kompyuter yoqilganda o'zi ochilishi) uchun shu
  kompyuterda bir marta, PowerShell'ni administrator sifatida ochib:

     powershell -ExecutionPolicy Bypass -File avtozapusk.ps1
     powershell -ExecutionPolicy Bypass -File avtozapusk.ps1 -Off     (o'chirish)
     powershell -ExecutionPolicy Bypass -File avtozapusk.ps1 -Status  (holati)

  Skript shu yerda: server\deploy\windows\avtozapusk.ps1


----------------------------------------------------------------
  BIRINCHI ISHLAR (tizimga kirgandan keyin)
----------------------------------------------------------------

  1. Sozlamalar -> parolni almashtiring (Admin12345 hammaga ma'lum)
  2. Xodimlar -> har bir xodimga alohida hisob oching
       (umumiy hisob ishlatmang - audit jurnalining ma'nosi shunda)
  3. Xodimlar -> "Rasm"        - xodim rasmini qo'ying
  4. Xodimlar -> "PIN qo'yish" - qisqa kod bilan kirish uchun
  5. Analiz katalogi -> o'z analizlaringiz va narxlaringizni kiriting

  * XODIM RASMI - kirish oynasida, "hozir kim ishlayapti"
